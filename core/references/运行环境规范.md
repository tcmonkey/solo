# Runtime capability standard

## Identify the runtime

Treat the host runtime and the model provider as separate facts. Record the host in `runtime.platform` and `last_actor.platform`; record the actual model in the corresponding model fields when known. Do not infer tools or permissions from a model name.

Examples of hosts include Codex, Claude Code, Qwen Code, an Agent Skills upload host, or a plain chat application. Examples of models include OpenAI, Claude, Qwen, DeepSeek, GLM, or Doubao model variants.

## Detect only relevant capabilities

Before relying on a capability, determine and record one of the following values or leave it `unknown`:

- `filesystem`: `read-write`, `read-only`, or `unavailable`;
- `shell`: `available` or `unavailable`;
- `python`: detected command such as `python3` or `python`, or `unavailable`;
- `repository`: `local`, `connected`, or `unavailable`;
- `browser`: `available` or `unavailable`;
- `persistence`: `durable`, `session-only`, or `unavailable`.

Do not ask about every capability up front. Inspect the host and request user input only when the next phase materially depends on an unknown capability.

## Degrade explicitly

- With a writable filesystem and Python, use the supplied scripts.
- With a writable filesystem but no Python, render the templates from `assets/` manually and perform structural checks without claiming the scripts ran.
- With read-only repository access, create exportable artifacts outside the repository only when the host supports it and the user authorizes the destination.
- Without persistent storage, return downloadable or copyable artifacts plus `state.json` and `18 交接记录.md`; label persistence as `not_persisted`.
- Without shell or repository execution, do not claim compilation, tests, linting, code review execution, or deployment. Record each unavailable check as `not_run`.

Host capability limits never authorize a different external side effect. Deployment, publishing, merging, production writes, and external messages still require the user's explicit request.
