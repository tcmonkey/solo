# 运行环境与能力规范

## 识别运行环境

宿主平台和模型提供方是两个独立事实。宿主记录在 `runtime.platform`、`last_actor.platform`；已知的实际模型记录在对应 model 字段。不从模型名称推断工具或权限。

宿主包括 Codex、Claude Code、Qwen Code、支持上传 Agent Skills 的平台或普通聊天应用；模型包括 OpenAI、Claude、Qwen、DeepSeek、GLM 或豆包的具体模型。宿主支持范围以实际维护和验证结果为准。

## 只检测当前阶段相关能力

依赖某项能力前，确认并记录下列值；未确认时保留 `unknown`：

- `filesystem`：`read-write`（可读写）、`read-only`（只读）或 `unavailable`（不可用）；
- `shell`：`available` 或 `unavailable`；
- `python`：检测到的命令，例如 `python3`、`python`，或 `unavailable`；
- `repository`：`local`（本地）、`connected`（已连接）或 `unavailable`；
- `browser`：`available` 或 `unavailable`；
- `persistence`：`durable`（持久）、`session-only`（仅当前会话）或 `unavailable`。

不在开始时逐一询问所有能力。先检查宿主，只有下一阶段实质依赖未知能力时才向用户询问。

## 明确降级

- 文件可写且有 Python：使用随包脚本；
- 文件可写但无 Python：依据 `assets/` 手工生成文档与状态，做结构检查，不声称执行过脚本；
- 仓库只读：仅在宿主支持且用户授权目标位置时，向仓库之外导出文档；
- 无持久存储：提供可下载或复制的文档及 `state.json`、`18 交接记录.md`，持久化结果标为 `not_persisted`；
- 无 Shell 或仓库执行能力：不声称执行过编译、测试、静态检查、代码审查执行或部署；不可用检查逐项标为 `not_run`。

宿主能力限制不授权其他外部副作用。部署、发布、合并、生产写入和外部消息仍须用户明确要求。
