# 界面与交互设计阶段规范

## 启用条件

出现新页面、新导航、重要交互变化，或不能依据已有设计系统确定视觉一致性时启用。已有组件仅有少量文案或布局调整时，在产品文档记录相关状态，并注明跳过本阶段的原因。

## 输入

在材料可用时检查截图、设计稿、品牌素材、现有应用、组件库及响应式行为。缺乏依据的视觉决策须明确说明。

## 界面设计文档

采用 `assets/03 界面设计方案.md` 模板，包含：

- 页面清单与层级；
- 带说明的用户流程；
- 组件及复用映射；
- 内容层级和文案；
- 交互及状态切换行为；
- 加载、空数据、成功、错误、禁用和权限状态；
- 校验提示；
- 响应式断点或适配规则；
- 键盘操作及无障碍行为；
- 视觉参考和未决设计问题。

使用 `SCREEN-###`、`COMP-###`，将页面关联到 `FLOW-###` 和需求。

## 质量要求

方案必须可实现、可测试。没有测量数据或权威设计来源时，不承诺像素级还原。
